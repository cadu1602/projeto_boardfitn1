# 🏄‍♂️ BoardFit — O seu Shaper Virtual


O **BoardFit** é uma solução web desenvolvida para ajudar surfistas a encontrarem a prancha ideal com base em seu peso, altura e nível de experiência, eliminando escolhas incorretas e prejuízo financeiro.
